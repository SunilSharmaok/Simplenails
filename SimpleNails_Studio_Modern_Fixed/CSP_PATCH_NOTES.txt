SimpleNails — Google Login CSP fix

Root cause confirmed by browser Console:
CSP script-src blocked https://apis.google.com/js/api.js.

Changed: backend/server.js (Helmet Content Security Policy)
 - Added https://apis.google.com to scriptSrc (required).
 - Added https://apis.google.com and https://www.gstatic.com to connectSrc (secondary).

Quick fix for existing installation:
1. Find currently running SimpleNails_Google_Login_Fix\backend folder.
2. Replace backend\server.js with the corrected server.js from this package.
3. Wait for nodemon to restart or run npm run dev inside backend.
4. Open http://localhost:5000, Ctrl+Shift+R and test Google login again.

No secret .env is shipped. Keep your original .env in backend.

Tracking Prevention warnings on CDN assets and favicon.ico 404 are separate warnings.
Firebase Console and real Google sign-in still must be verified in your browser.
